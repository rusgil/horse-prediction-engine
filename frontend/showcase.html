The technical stack

Six engineering disciplines, one codebase — each one a competency in its own right.

🤖

Agentic AIAutonomous operations

The platform doesn't just run — it operates itself. In-process schedulers and scheduled cloud AI agents handle enrichment, pre-warming, snapshotting, calibration and retraining, then verify their own fixes. Research agents feed an automated product backlog: every item is hypothesised, built, tested and proven out-of-sample — then auto-deployed to production when it clears the guardrails — with a human one-click promote/reject available as the override.

hypothesise → build → test → prove → ✓ promote / ✗ reject
29 cron jobs APScheduler scheduled cloud agents automated product backlog one-click promote / reject refine→backtest→release gate guardrailed auto-promotion
📈

Predictive ModelsWin, place & exotic models

Separate win, place and exotic models over 41 engineered features distilled from 60+ per-runner signals — form, class, pedigree and live market microstructure — 14M+ feature values computed across 347k prediction records. A Benter-style market+model blend, Harville / Plackett–Luce joint probabilities for exotics, walk-forward backtesting and sample-size-gated calibration.

41 features 13.6M feature values win · place · exotic Benter blend Harville / Plackett–Luce isotonic calibration multi-window backtesting candidate vs incumbent walk-forward, no test-on-train
🗄️

Data EngineeringMulti-source ingestion

Nine client adapters reconcile racing cards, tote & bookmaker odds and weather into a 60-table schema — with upstream-site awareness and persistent caches that keep sourcing responsible and well inside every provider's rate limits. The schema is tuned for speed: proper keys and 131 targeted indexes took hot queries from ~700 ms to ~5 ms — a ~140× speedup.

9 adapters official racing data bookmaker odds composite odds 700ms → 5ms 131 indexes resilient / auto-healing ingestion
🛡️

Security & IntegrityIntegrity guardrails

Write-once prediction history with a tamper guard and an incidents ledger; continuous integrity capture that auto-heals detected issues — duplicate results, scratch mismatches, upstream gaps; built-in agentic-AI guardrails for continuous data-integrity and trust protection; and secret hardening — auto-generated API docs, per-purpose token migration, open-proxy sentinel.

write-once history tamper guard + incidents ledger auto-healing guardrails integrity baseline/EOD secret hygiene
⚙️

API & BackendAsync FastAPI

A 229-endpoint FastAPI service — 179 of them admin/ops operations — on fully async SQLAlchemy 2.0 and asyncpg, typed end-to-end with Pydantic v2, with response middleware enforcing cross-cutting rules on every current and future route.

229 endpoints 179 admin ops FastAPI Python query (SQLAlchemy / asyncpg) Python data validation (Pydantic v2) OpenAPI

Infra & CI/CDInfrastructure as code

Backend on Railway (managed Postgres), three globally-edged frontends on Vercel, a Terraform-managed reverse-proxy tier on its own cloud host with Caddy/TLS — all wired under a self-registered domain, with DNS routing the API host and a subdomain per product. Static UI served from a global edge CDN. Push-to-deploy continuous delivery with pre-deploy compile & lint gates. Config-driven and stateless throughout.

03

The agent fleet

Seven autonomous agents keep the platform sharp, honest and safe — every night, with no human in the loop. Operations, continuous model improvement and security review — each with its own named specialist.

Research · the self-driving loop In design · shipping next
⚗️
The Alchemist
Hypothesis · generator

Reads the data, the misses and the market for patterns worth chasing, and frames each as a falsifiable, testable hypothesis — the raw ore the Labs exist to refine.

  • Mines: losing patterns, market disagreements, untested feature interactions.
  • Frames: a precise hypothesis with a measurable success bar.
  • Queues: hands it to the Crucible with the exact test to run.
🔥
The Crucible
Hypothesis · solver

Takes each hypothesis and burns it down — building the out-of-sample backtest, running it against real history, and returning a hard verdict: ship it, or reject it.

  • Builds: the walk-forward, no-leak experiment for the claim.
  • Tests: against thousands of settled results — adversarially, trying to falsify.
  • Verdicts: survivors go to the release gate; the rest are logged and rejected.
The Alchemist dreams up an edge  →  The Crucible tries to destroy it  →  only what survives ships  ↺  research that runs itself
Operations · keeping the model sharp & honest
🌙
Night Watch
Model Ops · nightly → morning

While the tracks sleep, Night Watch re-grades the models against the day's real results, recalibrates them out-of-sample, and lands a morning report of exactly how much the model improved overnight.

  • Nightly backtest: every model re-scored on fresh settled results — walk-forward, clipped at the holdout boundary so it's never test-on-train.
  • Recalibration: weight & probability calibration sweeps refit on the new evidence.
  • Multi-model comparison: candidate models trained over different lookback windows, their outputs raced against the incumbent out-of-sample — only the strongest is put forward.
  • Weekly review: generates the weekly performance review and seeds follow-up tasks; a daily resolver works the queue.
  • Morning report: before/after win & place delta — the night's improvement, in your inbox.
  • Guardrail: the strongest candidate auto-promotes to production each week — the gate is backtest-beats-incumbent + drift detection + auto-rollback, not a human click.
🏛️
The Governor
Integrity & Safety · continuous

The Governor watches every write for the truth to slip — scanning for integrity incidents (duplicate results, mismatches, post-race rewrites, upstream data gaps) and reporting them. And when it's serious enough, it pulls the handbrake.

  • Incident scan: duplicate finishing positions, result mismatches, silent post-race rewrites, upstream feed gaps.
  • Full integrity reporting: 5-minute baseline capture through the day + a nightly end-of-day reconciliation, logged to an incidents ledger.
  • Immutable history: predictions are write-once behind a tamper guard — confirms the guard held.
⛔ Circuit breaker: on a major event — a degraded prediction distribution or contaminated data snapshot — the Governor raises a site-wide safe-mode splash, filters the bad data out of every response, and effectively takes the site offline until health returns, then clears itself automatically once the backlog drains.

The stat sheet never tells you a captain rolled an ankle at Thursday's captain's run, or that a locker room's in open revolt. The Socialite does. For every NRL side, it reads the room — then hands the match model a sentiment signal the box score can't see.

Security · the purple team
🦹
Dr Evil
Red Team · continual scan · always learning

Thinks like an attacker against FunkyIQ's own surface, confirms each weakness with the lightest possible proof, and files ranked threat reports — then stops. It finds holes and threatens loudly; it never detonates.

  • Continual vulnerability scanning: every night sweeps the whole surface fresh — nothing is assumed still-safe because it passed yesterday.
  • Always learning: pulls the latest security advisories (CVE/NVD, CISA KEV and GHSA) and cross-checks them against the live dependency versions — new threats become new checks automatically.
  • Static review: traces SQL injection to its source, and hunts remote code execution and unsafe deserialization, server-side request forgery (SSRF), cross-site scripting (XSS) and leaked secrets — each confirmed class becomes a permanent regression check.
  • Probes: tests against the OWASP Top 10 for web and APIs — the industry-standard checklists of the most critical security risks — read-only, rate-limited, with a single harmless proof per finding.
  • Guardrails: allowlisted scope, ≤30 req/min, halt-on-critical, secrets masked.
⚡
Thor
Blue Team · continuous

The guardian. It detects real attacks, watches data integrity and availability, verifies Dr Evil's findings and drives each to closure — doing the safe, reversible defence itself and proposing the risky stuff.

  • Real-time log & anomaly detection: streams access and error logs live, flagging anomalies as they happen — auth-failure spikes, unusual admin-route hits, traffic that breaks the baseline.
  • Watch: integrity violations, secret leaks, bandwidth headroom, cert expiry.
  • Repair: triage findings, re-test fixes, harden config, close the loop.
  • Respond: run known recovery playbooks — safe steps auto, risky steps proposed.
  • Least privilege: read-mostly, every write narrow, reversible and logged.
Dr Evil proves the door can be forced  →  security findings store  →  Thor mends the lock & sounds the horn  ↺  the purple loop

Labs · continuous research

A working model is never finished. The Labs are where agentic AI is applied to every edge being hypothesised, tested against real outcomes, and either shipped or rejected — with the discipline to reject far more than ships.

🔬

Live experimentsThe lab bench

A dedicated research surface where strategy ideas run as tracked, live experiments — including a full exotic-betting simulator that stakes candidate bets, counts down to the jump, and settles them against the real dividend.

tracked experimentslive simulationreal-dividend settlement
📐

Rigorous methodTest to destruction

Every hypothesis is measured walk-forward and strictly out-of-sample against thousands of settled results and real exotic dividends — never test-on-train. A candidate only reaches production through refine → backtest → release.

walk-forwardout-of-samplerefine → backtest → release
The discipline is in the rejection. Collateral-form Elo, exotic-spread structures, blind-shrinkage — all hypothesised, fully backtested, and rejected when the out-of-sample lift wasn't there. Intellectual honesty over hype: most good-sounding edges are noise, and the Labs are built to prove it.
This loop runs itself — The Alchemist dreams up an edge, The Crucible tries to destroy it, and only what survives ships. Meet them both in the agent fleet above. In design · shipping next

Principles

How this platform gets built — and how I work.

01
Integrity by design
Integrity is guaranteed at the data layer — write-once history, auto-healing guardrails — not hoped for.
02
Guarded autonomy
Machines discover, validate, operate and promote themselves — the guardrails (backtest-beats-incumbent, drift detection, auto-rollback) are the gate, not a human click.
03
Prove it out-of-sample
Every claim is walk-forward tested against real outcomes. Reject more than you ship.
04
AI-First ModelOps
The model is perpetually retrained and recalibrated with automated drift detection — the strongest candidate auto-promoted to production each week, guardrailed by auto-rollback on live regression.
05
Own the whole stack (Full-Stack Engineering)
From DNS, proxies and infra through to the data, models and UX design. Version-controlled code with automated deployment featuring AI-driven issue-detection and auto-healing capabilities.
